# Template Latex para Trabalho de Conclusão de Curso - UNIVASF 🎓

Este repositório contém o código-fonte em LaTeX exigido no Trabalho de Conclusão de Curso (TCC) para o curso de graduação em **Engenharia da Computação** pela **Universidade Federal do Vale do São Francisco (UNIVASF)**.

* **Julia Cardoso Reis**

## 📝 Estruturação do Template:
**imagens:** Pasta que deve conter todas as imagens utilizadas na monografia. Deixei um exemplo no arquivo de como importar uma imagem corretamente. 

**pretextual:** Pasta que contém as folhas que antecedem o Sumário; pela norma ABNT, são folhas que não podem conter numeração. Escolhi colocá-las numa pasta, para além de organização, por serem elementos que são editados poucas vezes.  

Arquivos como *introducao.tex, ....referencial.tex......etc* que são os arquivos que constituem o corpo de TCC, o qual o(a) estudante irá alterar diversas vezes até atingir a versão final. Pensando na praticidade de se mover entre os capítulos durante a escrita, optei por deixar estes arquivos fora de qualquer pasta. Por este mesmo motivo, os arquivos: *resumo.tex , abstract.tex e agradecimentos.tex* , embora estejam antes do **Sumário** , como são arquivos que passam por sucessivas edições, foram posicionados fora de patas também.

*O Template está bastante legível. Você pode baixar este repositório na sua máquina e reorganiza-lo do jeito que bem entender sem muito esforço.* 


## 🚀 Como utilizar/compilar
Este projeto foi desenvolvido focado no [Overleaf](https://www.overleaf.com/). Caso queira compilar localmente na sua máquina, você precisará de uma distribuição LaTeX (como TeX Live ou MiKTeX) e utilizar o compilador adequado em conjunto com o `biber` para a geração das referências.
